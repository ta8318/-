# 아파트 바이러스 퇴치단

아파트 9세대에 나타나는 바이러스를 한글 타자로 없애는 게임입니다.

- 감염된 집의 단어를 입력하고 Enter를 누르면 바이러스가 사라집니다.
- 바이러스의 시간 막대가 소진되면 목숨이 하나 줄어듭니다.
- 목숨 5개로 시작하며, 5단계를 모두 완료하면 승리합니다. 목숨은 단계가 바뀌어도 회복되지 않습니다.
- 각 단계 목표는 5·7·9·11·13마리입니다. 단계가 높아질수록 출현 간격과 퇴치 제한 시간이 짧아집니다. 전체 시간 제한은 없습니다.
- `처음부터` 또는 `다시 도전` 버튼으로 재시작할 수 있습니다.

## 실행

`index.html`을 브라우저로 열거나 저장소 폴더에서 실행하세요.

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

외부 패키지, API 키, 빌드 과정이 필요하지 않습니다.
